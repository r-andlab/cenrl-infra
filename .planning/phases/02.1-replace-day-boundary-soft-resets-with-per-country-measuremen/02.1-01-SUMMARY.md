# Phase 02.1 Plan 01: Per-country measurement-count soft-reset on RegionalNode Summary

**Replaced the `_finish_episode_if_ready` "idle until midnight" branch with an active per-country reset that writes a per-iteration CSV snapshot, rolling-appends the country CSV, snapshots `state/iterations/iter_NNN.{graphml,json}`, and bumps `episode_idx` — all without cross-country coordination.**

## Accomplishments

- New `RegionalNode.save_iteration(idx, state_dir)` writes `<state_dir>/iterations/iter_NNN.{graphml,json}` atomically by reusing the Phase 02 primitives `checkpoint_save` (mutation-safe GraphML) and `_write_sidecar` (.tmp + os.replace JSON). Re-raises after logging so the caller owns fault isolation.
- `RegionalNode.write_stats()` rewritten for D-05: a per-iteration snapshot CSV (`<country>_iter_NNN.csv`, full overwrite each call) and a rolling per-country CSV (`<country>.csv`, `mode="a"` with header-on-first-write only). Clears `episode_all_stats` post-write so the next iteration's rotate-then-write does not double-append. Legacy `stat_df` overwrite branch preserved for external test harnesses.
- `RegionalNode.soft_reset()` now increments `self.episode_idx` (D-04) so the per-country iteration counter advances independently per country. Q-value preservation (no `model.reset()` call) is preserved.
- `RegionalNode._finish_episode_if_ready()` replaces the idle-until-midnight branch with the active reset: rotate `episode_stats → episode_all_stats`, call `write_stats → save_iteration(episode_idx, state_dir) → soft_reset` in strict order (D-08), wrapping each save in try/except so a failure logs and continues but soft_reset always runs.
- 24 new unit tests (5 + 11 + 7 plus 1 new TestSoftReset method) covering ordering, fault isolation, episode_idx semantics, file naming, atomic writes, and the no-rows / repeated-idx edge cases. Full `tests/infrastructure/test_node.py` suite is green at 45 passing.

## Decisions Made

- **save_iteration error policy:** the method re-raises after logging, deferring per-country fault isolation to the caller (`_finish_episode_if_ready`). This mirrors the orchestrator-side Phase 02 `_perform_soft_reset` pattern, where the per-country try/except wrapped `save_daily`. Keeping `save_iteration` itself "honest about failures" lets future callers decide their own policy (e.g., a future signal-handler save path might want the exception to propagate).
- **episode_all_stats clearing inside write_stats:** moved the clear from the caller (where the rotation lives) into the callee (write_stats), so the contract is: caller rotates rows IN, callee consumes and clears the buffer. This prevents the next iteration's rotate-then-write from double-appending the rolling CSV. Tested by `test_clears_episode_all_stats_after_write`.
- **TestFinishEpisodeIdleNotDone helper rebuild:** the old helper was filesystem-free because the old code path was filesystem-free. The new code path triggers real `write_stats` and `save_iteration` calls, so the helper now allocates a `TemporaryDirectory` and provides every sidecar field `_write_sidecar` reads. Tests that don't actually exercise the filesystem still use the helper unchanged but pay a few μs for tempdir allocation.
- **`TestWriteStatsNullSafe.test_write_stats_flushes_partial_stats` update:** the original assertion (`mock_csv.assert_called_once()`) was tied to the pre-D-05 single-write contract. Under D-05, `write_stats` produces TWO files (snapshot + rolling), so the assertion is now `call_count == 2`. The test still verifies the original behavior (write_stats flushes partial stats when stat_df is None), just with the new contract's call multiplicity.
